# char

A vim-like text editor with pleasant defaults and zero required configuration.

char aims to be fast, versatile and reliable.

> [!NOTE]
>
> char is in early stages of development.

## Roadmap
The high-level ambitious plan for the project, in order:

|  #  | Step                                                    | Status |
| :-: | ------------------------------------------------------- | :----: |
|  1  | Vim motions                                             |   ✅   |
|  2  | Syntax Highlighting                                     |   ✅   |
|  3  | Multiple Buffers                                        |   ❌   |
|  4  | Config file                                             |   ❌   |
|  5  | Colorschemes                                            |   ❌   |

## Installation

### Install via Script

**Linux and macOS:**

```sh
curl -fsSL https://raw.githubusercontent.com/rhemab/char/main/install.sh | sh
```

### Install via Cargo
```sh
cargo install char --locked
```
